# Dr. Moiz Dental Clinic 🦷

A highly premium, minimal, and responsive dental clinic website built to establish authority, build patient trust, and streamline appointment bookings.

## 🌟 Key Features
- **Modern Tech Stack:** Built with Next.js (App Router) for optimal performance and SEO.
- **Premium Aesthetics:** Custom minimalist color palette (Off-White, Primary Blue, Secondary Yellow) using Tailwind CSS v4.
- **Smooth Animations:** Integrated Framer Motion for high-end scroll reveals and transitions.
- **Patient-Centric Layout:** Includes Z-pattern clinical expertise showcases, interactive bento-grid galleries, and a dedicated lead generation booking form.
- **Responsive Design:** Flawless experience across desktop, tablet, and mobile devices.

## 💻 Technologies Used
- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide Icons / Custom SVGs
